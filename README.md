HR Analytics: Dashboard de Visualización de Talento Humano
Este proyecto forma parte de mi portafolio para Prácticas en Data Analysis. En esta entrega, el foco principal es la visualización de datos y la creación de dashboards interactivos que faciliten la toma de decisiones estratégicas en el área de Recursos Humanos.

🎯 Objetivo del Proyecto
Analizar la retención y el perfil demográfico de los empleados para identificar patrones de rotación y áreas de mejora en la satisfacción laboral.

Nota: Aunque este repositorio se centra en la visualización, realicé una extracción previa mediante PostgreSQL y limpieza en Excel para asegurar la calidad de la información.

🛠️ Stack Tecnológico
Visualización: Power BI & Tableau Desktop.

Procesamiento de Datos: SQL (PostgreSQL) y Excel (Tablas dinámicas y Power Query).

Documentación: Markdown.

📊 Visualizaciones Destacadas
1. Dashboard en Power BI
Foco: KPIs operativos y métricas de rotación.

Métricas Clave: Tasa de atrición, promedio de edad, años de servicio y satisfacción por departamento.

🧠 Insights Identificados
A través de las visualizaciones, se determinaron los siguientes puntos clave:

Punto de Deserción: Se identificó una tendencia de salida en empleados con menos de 2 años en la empresa.

Satisfacción vs. Rotación: Los departamentos con menor índice de satisfacción ambiental muestran una correlación directa con la tasa de renuncia.

Demografía: El balance de género y la educación técnica son factores determinantes en la estabilidad de ciertos roles analizados.

📁 Estructura del Repositorio
/Data: Contiene el dataset utilizado (HR Data).

/SQL: Scripts de PostgreSQL utilizados para las consultas iniciales.

/Dashboards: Archivos .pbix y .twb (Power BI y Tableau).

/imagenes: Capturas de pantalla de los dashboards finales.

🚀 Cómo visualizar el proyecto
Descarga los archivos de la carpeta /Dashboards.

Para Power BI: Necesitas tener instalado Power BI Desktop.

Para Tableau: Puedes abrirlo con Tableau Desktop o subirlo a Tableau Public.
